# 控制台 UI 复刻优化 · 2026-11-01

## 已实施
- 自主实现深色灰阶控制台、浅色主题切换与本地外观偏好、侧栏收放、统一按钮/卡片/弹窗；使用回响品牌，不导入第三方构建脚本或 CDN。
- 可补日志改为模型分组、次数/可申请笔数/预计额度摘要、展开明细；桌面表格、移动端卡片。
- 仅聚合本页上游数据，明确标识原始总数与分页口径；整数 quota 展示，不借用外站币种兑换。
- 申请、审核、逐笔金额核验和人工对账改为集中表单；依据必填、金额不预填、逐笔结果反馈。申请提交失败保留输入；管理动作结果未确认不在原弹窗重发。
- 成功补偿历史按规则时区的更新日期折叠分组，仅显示本页成功记录。
- 退出清除页面与操作草稿；旧账号/旧页面请求结果不渲染；保留后端权限、去重、预占、审核和 unknown 冻结逻辑。

## 仍有边界
这是第一轮参考式复刻，不宣称像素级一比一；未加入多实例、全量候选索引或自动补款。真实部署前继续完成原站接口、权限及到账联调。没有修改部署、数据库发现、云中猫API小站 源项目与额度执行代码。

## 第二轮：控制台交互补齐
- 移动端使用 320px 侧滑抽屉，包含分组导航、当前页面高亮、独立滚动和固定退出区。支持关闭按钮、遮罩、Escape、Tab 焦点圈定、背景 inert 与滚动锁定；导航后自动关闭，跨断点恢复桌面侧栏。
- 顶部补齐品牌、Lucide 菜单/搜索/主题按钮、头像账号菜单。搜索仅展示当前身份可访问页面，支持输入过滤和跳转。Lucide 由本地资源提供，许可证随文件保留，不依赖 CDN。
- 普通用户新增数据统计页：7/30/90 天、站点选择、手动刷新、60 秒自动刷新、按日趋势及日期滑杆、每日明细表。切走页面或退出停止计时；旧响应不覆盖新筛选。
- 新增 `/api/statistics`，服务端固定当前用户，按配置时区的执行日统计所有已确认成功记录，不受申请列表 30 条分页影响。范围只允许 7/30/90 天。
- 单实例下“全部站点”和“当前实例”指向同一数据集。钱包、提现和额度转移显示未接入，不冒充零余额，不模拟金融交易。外站的令牌、AI 工具、下载端、发票等页面尚未实现，菜单只保留当前项目已接入功能。
- 后端测试增至 34 项。浏览器回归增加抽屉开关、Escape、统计筛选、自动刷新开关保持、手机溢出、页面搜索、账号菜单；原申请/审核/执行闭环继续验证模拟增额仅一次。
