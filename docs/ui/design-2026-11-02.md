# 云响控制台 UI 设计 · 2026-11-02

状态：设计稿。本文件只定义视觉与交互，不改业务逻辑、额度计算、审批状态机或数据库。

参考对象是 tool.gemai.cc 的控制台壳：56px 顶栏、分组侧栏、毛玻璃卡片、可展开补回记录、蓝色主操作、绿色成功态。云响不复制对方商标、文案和未接入功能。单站点，不出现站点筛选。

## 1. 设计原则

1. 一层只做一件事。查询、可补结果、补回记录分成三段，不把空状态和操作挤在同一块灰底里。
2. 数字先于说明。额度、次数、状态是主信息；request_id、规则版本、时区是次信息。
3. 状态靠形状、文字和图标一起表达，不只靠颜色。
4. 所有可点区域最小 40px，移动端 44px。展开、选择、开关都用同一套毛玻璃控件。
5. 加载有过程。查询、提交、审批、到账各自有骨架或进度，不突然替换整页。
6. 额度展示跟随 云中猫API小站 显示配置。界面写「额度 380」，不写内部 quota 字段名，也不换算成未配置的货币。

## 2. 色彩

默认深色。浅色是同一套 token 的反相，不是另一套布局。

| Token | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| --bg | #0c1014 | #f4f6f8 | 页面底 |
| --bg-glow | #16304f / #0e2a28 | #dbeafe / #d1fae5 | 登录与页头两处很淡的光晕 |
| --surface | rgba(22,27,34,.78) | rgba(255,255,255,.82) | 卡片、侧栏、顶栏 |
| --surface-2 | rgba(255,255,255,.04) | rgba(15,23,42,.03) | 卡片内分区 |
| --line | rgba(255,255,255,.10) | rgba(15,23,42,.10) | 描边 |
| --ink | #eef3f7 | #14202b | 主文字 |
| --muted | #8b98a5 | #64748b | 次文字 |
| --accent | #3b82f6 | #2563eb | 主按钮、当前导航、图表、链接 |
| --accent-2 | #22d3ee | #0891b2 | 品牌高光，只用于 logo 环和主数字渐变 |
| --good | #34d399 | #059669 | 成功、已到账、可补 |
| --warn | #fbbf24 | #d97706 | 待审核、订阅转人工 |
| --bad | #f87171 | #dc2626 | 失败、拒绝、删除确认 |
| --info | #93c5fd | #2563eb | 自动审批中、说明 |

品牌不再用整块青绿铺满指标卡。青绿只留给成功和金额。主操作统一蓝色，和参考站按钮一致。

## 3. 字体与圆角

- 中文：`Segoe UI`, `Microsoft YaHei`, `PingFang SC`
- 数字：`ui-sans-serif` + `font-variant-numeric: tabular-nums`
- 标题 28 / 600 / -0.4px；区块标题 16 / 600；正文 14 / 1.6；说明 12；眉题 11 / 700 / 0.14em
- 圆角：控件 10，卡片 16，弹窗 20，胶囊 999
- 阴影只在浮层：`0 18px 50px rgba(0,0,0,.35)`。卡片靠描边和模糊，不叠厚阴影。
- 毛玻璃：`backdrop-filter: blur(18px) saturate(140%)`。`prefers-reduced-transparency` 时退回不透明表面色。

## 4. 布局

桌面 ≥1100px：

- 侧栏 248px，固定，自身滚动。
- 顶栏 56px，固定在主区顶部。
- 内容区最大 1240px，左右 28px，区块间距 20px。

900px 以下：

- 侧栏改为全高抽屉，宽 min(320px, 86vw)。
- 顶栏只留菜单、品牌、搜索、主题、头像。
- 面包屑隐藏。
- 四列指标改两列，700px 以下改一列。
- 表格改卡片，不让整页横向滚动。

侧栏结构：

```
云响                    [收起]
● 已连接 云中猫API小站

工作台
  我的概览
  数据统计
  可补空回

我的
  我的申请
  补偿记录
  补偿规则

站长
  管理概览
  申请处理
  补偿统计
  规则与数据
  通知
  操作记录
```

当前项：左侧 3px 蓝色条 + `accent 14%` 填充，图标同色。分组标题用 11px muted，上下留 18px。退出固定在抽屉底部，危险色文字，不做成大按钮。

顶栏：`工作台 / 当前页`。右侧搜索打开命令面板，只搜当前身份可见页面。

## 5. 组件

### 5.1 页头

左：眉题、标题、一行副标题。右：主操作或刷新。刷新是次按钮，带 16px 图标。统计页刷新和自动刷新放在筛选条，不重复放页头。

### 5.2 指标卡

四张同高。第一张可用金额用 32px 数字，颜色 `--good`，不做整卡反色。其余数字 `--ink`。标签在上，说明在下。未接入的数据写「未接入」，用一条短横线，不用假 0。

### 5.3 状态胶囊

| 状态 | 外观 |
| --- | --- |
| 补偿成功 | 绿底 12% + 绿字 + check |
| 自动审批中 | 蓝底 + 旋转环 |
| 待人工审核 | 黄底 + clock |
| 已拒绝 | 红字，无填充块 |
| 待对账 | 灰底 + 虚线框 |
| 执行失败 | 红底 12% |

胶囊高度 24px，圆角 999，字重 600。

### 5.4 分段条

申请处理中心顶部用毛玻璃分段，不把所有状态塞进一个表：

`待审核 · 审批中 · 补偿成功 · 未通过 · 待对账`

每段显示数量。当前段底部 2px accent。移动端横向滑动，不换行挤压。

### 5.5 可展开记录

对齐参考站补回记录，不用图片代替：

- 收起态一行：状态、时间范围、补回额度、模型数、创建时间、右侧 chevron。
- 展开：`grid-template-rows: 0fr → 1fr`，180ms。
- 内层按日分组，日汇总在左，模型行缩进 16px，左侧 2px accent 淡线。
- 模型行：名称、额度、次数。再展开才出现单笔 request_id。

同一用户同一次提交的多个模型，在处理中心合并成一张卡。卡头是用户、总额、状态、时间。打开后是模型明细，不是再弹一层原生 alert。

### 5.6 图表

统计页只保留「我的云响补额度趋势」。无站点筛选，无提现/转账空卡。

- 面积图：线 `#3b82f6` 2px，线下 18% 蓝色渐隐。
- 有数据的点 6px，0 值不画大圆点，避免一条珠链。
- 十字线和浮层跟手：日期、额度、次数。
- 空数据用 160px 空态，不画假趋势。
- 下方保留「查看每日明细」，默认收起。

### 5.7 查询区

可补空回页上段固定三步，不先铺空表格：

1. 当前账号胶囊：头像首字 + 用户名。没有「当前实例」。
2. 主按钮「查询空回」。查询中按钮内联 spinner，卡片切骨架。
3. 结果出现后再显示汇总：可补额度、模型数、笔数，以及模型分组。勾选后右侧固定「补额度」。

查询前，补回记录可以显示历史，但和查询区分开，避免一大块空白图标占据首屏。

### 5.8 表单与选择

所有输入、下拉、日期、多选、开关走毛玻璃，不用系统默认 `<select>` 外观。

- 输入高 42px，聚焦 2px accent 外环。
- 下拉层 `blur(24px)`，选中项 accent 字，不整行反色。
- 日期用自绘月历，和现有 glass calendar 同一语言。
- 开关 36×20，开为 accent。
- 危险输入（删除模型、清理数据）主按钮用 `--bad`，并要求二次确认句，不靠浏览器 `confirm()`。

### 5.9 弹窗

宽 min(640px, calc(100vw - 32px))。头：眉题 + 标题 + 关闭。身：可滚动。脚：取消在左，确认在右，移动端等宽。

处理弹窗内部分三块：账号与总额、模型明细、审批说明。订阅来源用黄色提示条：「审核通过后补进余额」。

成功到账使用全屏轻overlay 900ms：毛玻璃卡片、绿色对勾、额度数字、模型数。可跳过。`prefers-reduced-motion` 只保留结果条，不做缩放。

### 5.10 加载

- 首屏：指标卡和表格骨架，3 条 shimmer。
- 按钮：文字保留，左侧 14px 环。
- 顶栏 2px accent 进度，仅网络请求期间。
- 审批中：状态胶囊内环旋转，不锁死整页。

## 6. 页面

### 登录

保持左右分栏。左屏深色渐变 + 云纹，不是纯绿块。标题改为「空了有回响，额度回到余额。」品牌名云响，logo 优先 云中猫API小站 `/api/status` 的 logo，失败再用云图标。右屏登录卡居中，宽 400。没有独立注册。二次验证在同一张卡内替换，不跳页。

### 我的概览

四指标：累计补回、今日剩余额度、今日剩余次数、待审核。下面两列：最近申请、今日规则摘要。规则摘要只读，改规则入口指向规则页。

### 数据统计

工具条：近 7/30/90 天、最后更新、自动刷新、刷新。无站点筛选。一张趋势卡 + 每日明细。钱包、提现、额度转移未接入，不放空卡。

### 可补空回

见 5.7。补额度后：自动核验通过直接进入到账动画；不通过转入「待人工审核」，按钮变为「已提交审核」，不让同一笔再选。

### 我的申请 / 补偿记录

申请按状态分段。记录用 5.5 的展开列表。筛选收进「筛选」披露，默认只露出时间范围。

### 管理概览

四指标保留。最近申请表列：用户、补偿额度、状态、时间、进入详情。点击行进详情，不只有行尾小箭头。快捷入口两个：申请处理、补偿统计。

### 申请处理

分段：待审核、审批中、补偿成功、未通过、待对账。列表按用户合并。详情抽屉宽 480，桌面从右侧滑出；移动端全屏。审批按钮固定在抽屉底部。

### 补偿统计

这是唯一的汇总页。三个切换：用户、模型、渠道。每行可展开到明细。原始消费查询不再单独做一套相似总表；消费查询只保留「按 request 追查一笔」，入口放在统计页右上「追查消费」。

### 规则与数据

一个页，四个披露，避免重复页面：

1. 时间与限额：向前读取天数、每日额度、每日次数、零点或自定义刷新。
2. 可补渠道：读取 云中猫API小站 渠道，多选，不展示给普通用户。
3. 可补模型：按已选渠道拉取，多选。已下架/已删除模型单独一组，标记「补额需审核」。
4. 数据维护：清理预览、确认、保留账本说明。清理按钮危险色，预览先于执行。

### 通知

钉钉模板预览用真实排版，不用等宽代码块充当界面。示例：

```
云响 · 补偿成功
订单号
用户
类型 · 空回补额度
金额/额度
模型
时间
```

### 操作记录

时间线，不是宽表。每条：动作、对象、操作者、结果。展开看前后差异。

## 7. 动效

| 动作 | 时长 | 曲线 |
| --- | --- | --- |
| 悬停/聚焦 | 120ms | ease |
| 页面内容进入 | 180ms | ease-out，上移 8px |
| 展开记录 | 180ms | ease |
| 抽屉 | 220ms | cubic-bezier(.2,.8,.2,1) |
| 到账卡片 | 420ms | cubic-bezier(.2,1.2,.3,1) 后回正 |

减少动态效果时：时长变为 0，加载改文字「处理中」。

## 8. 与现有文件的对应

下一轮实现时只动这些展示文件：

- `public/style.css`：token、布局、侧栏、顶栏、指标、表格、登录。
- `public/glass.css`：表面、输入、分段、展开、弹窗、日历。保留现有控件增强，不另起一套 class。
- `public/index.html`：登录文案、品牌云响、顶栏高度所需的结构微调。
- `public/app.js`：导航分组文案、统计页去掉站点筛选和空卡、查询页三段结构、处理中心按用户合并的展示。不改接口字段含义。

不改 `src/service.mjs`、`src/rules.mjs`、`src/store.mjs` 的额度与去重逻辑。展示层继续调用现有 `formatQuota`。

## 9. 验收

- 1440、1280、390 三档无整页横向滚动。
- 深浅色下正文对比度至少 4.5:1，禁用态仍能读出标签。
- 键盘可完成：打开抽屉、搜索页面、查询、展开记录、关闭弹窗。
- 统计页不出现站点筛选、当前实例、未接入的钱包卡。
- 查询前不显示可补模型表；查询后显示额度与模型；成功有到账反馈；异常进入待审核。
- 站长四个状态分段可切换；同一用户多模型合成一张卡。
- 渠道和模型来自选择器，不出现手输模型名作为主路径。
- 额度文字与 云中猫API小站 显示配置一致。
